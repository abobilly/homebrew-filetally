# FileTally for Homebrew

FileTally counts pages and files locally. The Mac app requires macOS 14 or later and runs on Apple silicon and Intel Macs.

## Install

```sh
brew tap abobilly/filetally
brew trust abobilly/filetally
brew install --cask filetally
```

## Update

```sh
brew update
brew upgrade --cask filetally
```

## Uninstall

```sh
brew uninstall --cask filetally
```

Uninstall removes the app and leaves licenses, trial history and saved scans in place.

FileTally is proprietary software. See [FileTally licensing](https://filetally.com/licensing) for license and trial information.
